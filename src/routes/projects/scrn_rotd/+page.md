# Screen Rotate Daemon <IconButton class="inline-block mx-2" icon="mdi:github" href="https://github.com/jw910731/scrn_rotd" />

A daemon that constantly polls monitor orientation status using VESA DDC (I2C under the hood). When orientation changes, also changes the display orientation in Xwindow.

Since the monitor that triggers me to write this project is no longer used. This project is also abandoned.
